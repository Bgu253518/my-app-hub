# 标准项目框架模板

> 从「菡的工具箱」25 个实战工具中萃取的标准骨架。每一个文件、每一条规范都能追溯到工具箱里的真实出处。
> 学习笔记全文见桌面《工具箱架构学习笔记.md》（九个部分，含逐项目家谱）。

## 这是什么

做新工具时，不要从零开始。按本模板拷贝骨架 → 改两处名字（工具名、参数区）→ 得到一个**带界面、带日志、带编码链兜底、能直接跑**的工具。

## 怎么选档

| | B 档（工具箱成员） | A 档（独立分发） |
|--|------------------|----------------|
| 形态 | 归集进工具箱 `tools/项目N-xxx/` + 根目录 .bat 壳 | 单独发给同事，双击即用 |
| 界面 | web（pywebview） | web + tkinter 兜底 + PyInstaller exe |
| 引擎 | 同一份 core_engine.py | **同一份，不改** |
| 测试 | 可选 | 黄金样例测试（必须） |
| 打包 | 无（共享 `_runtime`） | build_exe.py |

**先 B 后 A**：工具在工具箱里用熟，要外发时补 A 档增强包，引擎零改动。

## 新工具五步

1. 拷 `B档-工具箱成员骨架/tools/项目N-新工具名/`，改工具名
2. 写 `config.py`（你的关键词表、阈值——照项目10 范式）
3. 写 `core_engine.py` 里的 `process()`（界面零改动）
4. 改 `web/index.html` 参数区 + `web/app.js` 传参
5. 过一遍 `99-验收清单.md`，注册进 `启动器/tools.json`
