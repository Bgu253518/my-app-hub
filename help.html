审计工具箱 · 使用说明

版本 2.1 · 更新日期：2026年8月 · 所有工具浏览器本地运行 · 数据不上传服务器

一、简介

审计工具箱是一套面向审计、财务人员的纯浏览器端工具集合。所有工具在本地运行，无需安装，数据不上传服务器。

  • 在线工具：打开浏览器即可使用。
  • 桌面工具：下载解压后双击运行。

二、快速上手

  1. 在首页搜索框输入关键词，或按分类筛选工具。
  2. 在线工具点击卡片即可使用；桌面工具点击下载后解压运行。
  3. 按页面提示上传文件或输入参数，处理完成后下载结果。

四、数据安全

  • 所有文件处理在浏览器本地完成（WebAssembly / Canvas / File API）。
  • 不上传服务器、不使用 Cookie、不嵌入第三方分析脚本。
  • 密码锁仅使用 sessionStorage，关闭标签即清除。

五、常见问题

Q：PDF 预览不显示？
A：刷新页面，确认浏览器支持 Web Worker。

Q：AI 助手加载失败？
A：首次需下载模型（约 600MB），推荐使用 Chrome 并支持 WebGPU。

Q：桌面工具无法运行？
A：Windows 可能提示 SmartScreen，点击「更多信息 → 仍要运行」。

Q：如何反馈需求或问题？
A：在首页「同事反馈」区登记，或访问 feedback.html。
