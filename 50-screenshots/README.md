# 工具截图替换说明

把工具的真实界面截图放到这个目录，首页的「工具界面一览」会自动读取。

## 命名规则

| 文件 | 对应工具 | 建议尺寸 |
|------|----------|----------|
| `audit-toolbox.png` | 审计工具箱合集（总览/控制台） | 800×600 或等比 |
| `pdf-toolbox.png` | PDF 多功能工具箱 | 800×600 或等比 |
| `rou-lease.png` | ROU 租赁管理系统 | 800×600 或等比 |
| `tb-smart.png` | TB 智能上数器 | 800×600 或等比 |

## 替换方法

1. 打开对应工具的页面（如 `app-slide.html?id=rou-lease`）。
2. 使用系统截图工具（Win+Shift+S）截取界面主体区域。
3. 保存为 PNG，按上表命名，放到此目录。
4. 刷新首页即可看到新截图。

如果某张图片不存在，首页会显示占位提示，不影响其他功能。
